# Redmine GitHub

Redmine GitHub(`redmine_github`)は、Redmine と GitHub をつなぐ Redmine のプラグインです。Redmine の標準のリポジトリ(サーバーに置いた Git などのリポジトリ)の代わりに、GitHub のリポジトリを GitHub App でつなぎます。今は検討段階で、資料だけがあります。

- [設計](design.md): 決めたこと、共通のゲートウェイ、流れ、まだ決めていないこと

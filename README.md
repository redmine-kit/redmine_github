# Redmine GitHub

[![License](https://img.shields.io/github/license/redmine-kit/redmine_github?label=License)](LICENSE)

Redmine GitHub (`redmine_github`) is a Redmine plugin that connects Redmine to GitHub. Instead of Redmine's standard repositories (Git and other repositories on the server), it connects GitHub repositories through a GitHub App.

[日本語](README.ja.md)

> **Status:** under consideration. The repository holds the design; nothing is implemented yet.

- It links issues to commits and pull requests also where repositories cannot be kept on the server, such as Redmine on AWS Lambda with [Serverless](https://github.com/redmine-kit/serverless).
- It also works with Redmine on an ordinary server.
